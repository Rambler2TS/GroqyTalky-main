GroqyTalky

v0.31

Hold a hotkey, speak naturally, and your cleaned-up words appear wherever your cursor is.

💬 What Does It Do?

GroqyTalky is a Windows voice-to-text tool that lives quietly in your system tray. Hold your chosen hotkey, say what you want to type, and release. Within a second or two, the cleaned-up text appears at your cursor — ready to use in any application: emails, documents, chat windows, search boxes, anywhere.

Under the hood it uses two AI services from Groq (both free at normal usage levels): the Whisper model to convert your speech to text, and a large language model to silently remove filler words (ums, uhs, false starts) before pasting.

Requirements Windows 10 or 11  ·  Internet connection  ·  Free Groq account (sign up at console.groq.com)

📦 Installation

  1. Unzip the downloaded file
    Extract GroqyTalky-installer.zip to any folder. You will see four files: GroqyTalky.exe, Run Me to Install GroqyTalky.bat, installer-core.ps1, and readme.htm. Keep all four together.
  2. Run the installer
    Double-click Run Me to Install GroqyTalky.bat. A black console window will appear briefly, then a folder-picker dialog will open.
  3. Choose your install folder
    Pick where you want GroqyTalky to live. The default (C:\Users\YourName\AppData\Local\GroqyTalky) works well and requires no administrator password. Click OK.
  4. Shortcuts are created automatically
    The installer adds a shortcut to your Desktop and Start Menu, and registers GroqyTalky in Windows Settings → Apps so you can uninstall it cleanly later.
  5. Launch GroqyTalky
    Double-click the Desktop shortcut. The first-time Setup Wizard will open automatically.
Troubleshooting the installer If the installer window flashes and closes instantly, make sure all four files (GroqyTalky.exe, Run Me to Install GroqyTalky.bat, installer-core.ps1, readme.htm) are in the same folder before running the bat file. The console window will show an error message if something is wrong — it will not close until you press a key.

🔑 First-Time Setup

When GroqyTalky launches for the first time, a Setup Wizard opens. Complete the steps below.

Step 1 — Get Your Free Groq API Key

  1. Go to console.groq.com and create a free account (or sign in if you have one).
  2. Click API Keys in the top navigation bar.
  3. Click the Create API Key button.
  4. Give it any name — it does not matter. Something like "GroqyTalky key" is fine.
  5. Click Submit, then copy the long key that appears on screen.
    6. Copy the key before closing that page! Groq only shows the full key once. If you close the page without copying it, you will need to create a new key.
  6. Paste the key into the Paste your key here field in the Setup Wizard and click Save & Start.

Step 2 — Set Your Recording Hotkey

Click the Click to Assign Hotkey button in the wizard. The button turns red and starts listening. Hold the key combination you want to use for at least 0.3 seconds, then release. The display updates in real-time as you press keys so you can see exactly what was recorded.

Good hotkey choices: something you would never accidentally press while typing. Examples: Right Alt alone, Ctrl + Win, Ctrl + Shift + F9.

Tip Avoid hotkeys that conflict with your other software. If the app does not seem to trigger, open Settings from the tray and reassign a different combo.

Preferences

The wizard includes a Media Ducking checkbox. When enabled, GroqyTalky automatically lowers the volume of all other apps (music, video, etc.) to 10% while you are recording, then restores them the moment recording stops. This makes it much easier to hear yourself speak without permanently changing any volume settings.

This setting can also be changed later from Settings / Change Hotkey in the tray menu.

Step 3 — Find the Tray Icon

After saving, GroqyTalky disappears from view — it runs entirely from the system tray (the small icons near the clock in the bottom-right corner of your screen).

If you do not see it: look for a small ^ arrow next to the clock and click it to expand hidden tray icons. Find the circle icon and drag it out onto the main taskbar so it is always visible.

🎙️ How to Use It

Hold-to-Talk (quick dictation)

Hold your hotkey, speak, then release. Recording starts after you hold the key for about 0.3 seconds and stops the moment you let go. The text is transcribed, cleaned up, and pasted at your cursor automatically.

Double-Tap to Latch (hands-free dictation)

Tap the hotkey twice quickly (within about 0.45 seconds). Recording latches on so you can speak freely without holding anything. Press the hotkey once more when you are done and the text will be transcribed and pasted.

Tray Icon Colors

Grey — idle, ready to record
Red — recording in progress
Yellow — transcribing & processing

You also hear a short beep when recording starts and another when it stops.

Best results Speak at a normal pace and volume. You do not need to slow down or over-enunciate. The AI handles "ums", "uhs", and false starts automatically — just talk naturally.

🖱️ Tray Menu Reference

Right-click the tray icon to access all options.

Menu ItemWhat It Does
Settings / Change Hotkey Re-opens the Setup Wizard so you can update your API key or reassign the recording hotkey.
Edit System Prompt… Advanced: customize the AI instructions used to clean up transcribed speech. A Reset to Default button is available inside this window. Most users never need to touch this.
Retry Last Recording Re-sends the most recent recording for transcription. Useful if the previous attempt failed due to a network issue. The last recording is always saved to disk so it survives even if you restart the app.
View Readme / Help Opens this user guide in your browser.
View Logs Opens the transcription log file (ramblings_log.txt) in Notepad. Each entry shows the timestamp, raw transcript, and cleaned-up version. Newest entries appear at the top.
Usage Stats Shows how many transcriptions you have done this session, this month, and in total.
Open config.json Opens the settings file directly. Advanced users can hand-edit hotkeys, thresholds, and the system prompt here. Back it up before making changes.
Quit Stops GroqyTalky completely. It will not restart until you launch it again.

📁 Files Created by GroqyTalky

All files are stored in the folder where you installed the app — nothing is written to hidden system locations.

FileWhat It Contains
.env Your Groq API key (stored locally, never transmitted anywhere except to Groq).
config.json Your hotkey assignment and other preferences.
ramblings_log.txt A running log of every transcription (timestamp, raw audio text, cleaned text). Newest entries are at the top.
last_recording.wav The most recent audio recording. Overwritten each time you record. Used by Retry Last Recording if a transcription fails.
data\usage_stats.json Transcription counts (session, monthly, lifetime).

🗑️ Uninstalling

Open Windows Settings → Apps (or Control Panel → Programs and Features), find GroqyTalky in the list, and click Uninstall. Alternatively, run Uninstall-GroqyTalky.ps1 directly from the install folder.

The uninstaller removes the executable, all data files (.env, config.json, ramblings_log.txt, last_recording.wav, data\), both shortcuts, and the Programs & Features entry.

🔧 Troubleshooting

Transcription quality is poor or words are wrong

  • Open Windows Sound Settings → your microphone → Properties → Enhancements and disable any noise suppression, echo cancellation, or audio enhancements. These can make the audio sound muddy to Whisper.
  • Make sure you are using the correct microphone. In Windows Sound Settings, set your preferred mic as the default recording device.
  • Speak closer to the microphone and reduce background noise.
  • If a transcription failed mid-session, use Retry Last Recording from the tray once your connection is restored.

The hotkey does not trigger recording

  • Check that the tray icon is grey (idle) — if it is yellow, a previous transcription is still processing.
  • Some hotkeys conflict with Windows or other software. Right-click the tray → Settings / Change Hotkey to assign a different combination.
  • Try running GroqyTalky as Administrator if other software is capturing the same hotkey.

Transcription fails / error message appears

  • Check your internet connection — GroqyTalky requires internet access to reach the Groq API.
  • Verify your API key is still valid at console.groq.com. If it has been deleted or expired, create a new one and paste it in via Settings / Change Hotkey.
  • Your recording is saved as last_recording.wav. Use Retry Last Recording from the tray once the issue is resolved.

Text is pasted in the wrong place or not pasted at all

  • Click inside the text field or document where you want the text before you press the hotkey. GroqyTalky pastes using Ctrl+V at wherever the cursor is at the end of processing.
  • Some applications block programmatic paste. Try using a plain text editor like Notepad to confirm pasting works, then investigate the specific app.

The tray icon is not visible

Windows hides new tray icons by default. Click the ^ arrow near your clock to expand hidden icons, find the GroqyTalky circle, and drag it out onto the main taskbar to keep it permanently visible.
